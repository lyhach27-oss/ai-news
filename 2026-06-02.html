오픈소스 물리 AI —
이미지/영상 1위
NVIDIA가 Cosmos 3를 발표했다. 4억 건의 실사·합성 영상·오디오·텍스트·액션 데이터로 학습한 오픈소스 물리 AI 세계 모델로, 텍스트→이미지 및 이미지→영상(오디오 제외) 두 리더보드에서 동시 1위를 달성했다. 로봇·자율주행 등 물리 시스템이 실제 환경을 예측·계획하도록 설계됐다. 단순 영상 생성기와 달리 액션 데이터 레이어로 기계의 실제 움직임 모델링이 가능하다. Stanford 의대 CRISPR 유전자 편집 실험에서 샘플 이동 자동화에 이미 실전 투입됐다.

IMAGE · COMFYUI
Luma UNI-1, ComfyUI
파트너 노드 통합 —
추론형 이미지 AI
Luma AI의 추론형 이미지 모델 UNI-1이 ComfyUI 파트너 노드로 정식 통합됐다. UNI-1은 디퓨전 모델이 아닌 디코더 전용 오토레그레시브 트랜스포머로, 텍스트와 이미지를 단일 시퀀스로 처리한다. 생성 전 프롬프트를 분해·계획하는 추론 단계를 거쳐 합성·구성을 사전에 설계한다. Google Nano Banana 2·OpenAI GPT Image 1.5 대비 추론 기반 벤치마크에서 상위를 기록하면서 비용은 10~30% 저렴하다. ComfyUI에서 Create·Modify 두 워크플로 지원이 가능하다.

Seedance 2.0,
ComfyUI 정식 통합 —
오디오·멀티샷 지원
ByteDance의 Seedance 2.0이 ComfyUI에 공식 통합됐다. 텍스트·이미지·영상·오디오 레퍼런스를 입력하면 단일 패스로 동기화된 오디오를 포함한 고품질 시네마틱 영상을 생성한다. 일관된 캐릭터 표현·정밀 카메라 무브·멀티샷 시퀀스 생성을 지원한다. AI 영상 아레나 블라인드 테스트 연속 상위권 모델의 로컬 구동이 이제 가능해졌다. 복잡한 API 설정 없이 기존 ComfyUI 워크플로에 즉시 통합해 원클릭으로 영상 생성 파이프라인을 구축할 수 있다.
