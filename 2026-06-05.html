행정명령 서명 —
국가보안 심사

Reve 2.0 —
4K 레이아웃 기반
이미지 AI 공개
Reve AI가 레이아웃 기반으로 이미지를 생성·편집하는 Reve 2.0을 출시했다. 생성 결과물에 세그먼트 레이블이 포함돼 전체를 재생성하지 않고 특정 부분만 수정할 수 있다. Arena.ai 텍스트-이미지 리더보드에서 OpenAI GPT Image 2에 이어 2위를 기록했다. 레이아웃 컨트롤이라는 새 패러다임으로 이미지 생성 AI 시장은 스타트업에 여전히 열려있음을 증명했다.

HappyHorse 1.0,
Runway API 통합 —
3~15초 영상 지원
