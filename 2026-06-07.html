ChatGPT
월간 사용자
10억 명 돌파

ChatGPT가 월간 활성 사용자 10억 명을 돌파했다. Sensor Tower가 로이터에 제공한 데이터 기준으로 2023년 출시 후 약 3년 만에 달성한 역사상 가장 빠른 기록이다. Google Maps, TikTok, Instagram, YouTube의 초기 성장을 모두 앞섰다. 현 성장세라면 OpenAI는 2026년 안에 주간 활성 사용자 10억 명도 달성할 전망이다. GPT-5.5 업그레이드와 엔터프라이즈 구독 급증이 주요 성장 동력으로 꼽힌다.

Anthropic
글래스윙
15개국 150곳 확대

Anthropic이 사이버보안 이니셔티브 Project Glasswing의 파트너 기관을 150개 추가, 15개국 이상으로 확대했다. 전력·수도·의료·통신·하드웨어 분야 핵심 인프라 벤더가 새로 합류했다. Claude Mythos를 활용해 출시 이래 1만 건 이상의 고위험 보안 취약점을 발견했다. 신규 참여 기관은 Anthropic 보안 기준을 통과한 뒤 접근 권한을 부여받는다. AI로 공격자보다 먼저 취약점을 찾는 선제 방어 모델이 주목받고 있다.

FLUX.2 Klein
ComfyUI KV캐시
노드 정식 지원

ComfyUI에 FLUX.2 Klein 전용 KV캐시 노드(FluxKVCache)가 공식 추가됐다. NVIDIA가 Black Forest Labs·ComfyUI 팀과 협력해 FP8 퀀타이제이션 및 RTX GPU 최적화를 적용, 4B·9B 두 파라미터 버전 모두 VRAM 40% 절감·추론 속도 40% 향상을 달성했다. 새로 추가된 ByteDance2Reference 노드는 자동 업스케일 기능을 지원한다. 소비자용 GPU에서도 서브초(sub-second) 이미지 생성이 가능해져 로컬 생성 환경이 대폭 개선됐다.

공식 출시

Seedance 2.0
개발자 API
저작권 분쟁으로 지연

ByteDance의 Seedance 2.0 공식 개발자 API가 아직 출시되지 않았다. 할리우드 스튜디오와의 저작권 분쟁이 해소되지 않아 ByteDance가 직접 API 출시를 보류 중인 것으로 알려졌다. 현재는 서드파티 플랫폼들이 라이선스 계약을 통해 Seedance 2.0을 서비스하고 있다. 그럼에도 텍스트-투-비디오 블라인드 테스트에서 꾸준히 최상위권을 기록하며 존재감을 유지하고 있다. 저작권 문제 해결 시 API 출시 후 영상 AI 시장에 큰 파장이 예상된다.
