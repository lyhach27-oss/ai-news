CAT.01 · AI 빅뉴스
GitHub Copilot
AI Credits
도입
Microsoft GitHub이 6월 1일부터 Copilot 요금을 요청 횟수 기반에서 사용량 기반 종량제로 전환했다. 가상 화폐 'GitHub AI Credits'가 도입되어 실제 AI 기능 사용에 비례 과금된다. 개발자들은 Credits 소진 속도를 기준으로 비용 최적화가 가능해진다. GitHub Advanced Security 구독자는 우선 마이그레이션 경로가 제공된다. AI 코딩 도구의 실질적 가치를 사용량으로 증명하려는 Microsoft의 핵심 전략 전환이다.

OpenAI Codex
Windows PC
자율 제어 탑재
OpenAI Codex 앱이 Windows 11에서 'Computer Use' 기능을 지원한다. AI가 독자적으로 프로그램을 조작하고 앱을 테스트하며 버그를 자동 탐지한다. PC 부재 중에도 자율 개발 작업이 가능하며 ChatGPT 모바일 앱으로 원격 제어도 지원된다. 코딩 에이전트가 GUI 컨트롤까지 통합하면서 소프트웨어 개발 자동화 범위가 전체 주기로 확장됐다. Salesforce는 Claude Code 도입으로 231일 마이그레이션을 13일에 완료했다고 밝혀 에이전트 코딩의 파급력을 실증했다.

SoftBank Roze
AI 로봇 IPO
$1,000억 추진

CAT.02 · 이미지 / 영상 AI
FLUX.2 Klein
LoRA Loader
ComfyUI 출시
FLUX.2 Klein 9B 모델 전용 ComfyUI 커스텀 노드 'FLUX.2 Klein LoRA Loader'가 공개됐다. 아키텍처를 인식해 Diffusers 포맷 LoRA를 네이티브 FLUX 포맷으로 자동 변환하며 레이어별 강도를 정밀 캘리브레이션한다. 기존 포맷 불일치로 빈번하던 호환성 문제를 근본적으로 해결한 노드다. FLUX.2 기반 이미지 생성 워크플로에서 LoRA 활용도를 크게 높일 핵심 업데이트로 평가된다.

ComfyUI
Realtime LoRA
실시간 학습 지원
ComfyUI 내에서 LoRA를 직접 학습하고 블록 단위로 편집한 뒤 즉시 저장하는 'Realtime LoRA' 노드가 공개됐다. Z-Image, FLUX Klein, SDXL, FLUX, WAN 2.2, SD 1.5 등 주요 모델을 모두 지원한다. 별도 학습 환경 없이 ComfyUI 워크플로 안에서 완전한 LoRA 학습 사이클이 완성된다. 창작자가 실시간으로 스타일을 조정하며 반복 실험할 수 있어 이미지 AI 워크플로 효율이 크게 향상된다.

Infinity 2.0 Pro
출시

FLUX.1 Krea [dev]
BFL·Krea 협업
공개
Black Forest Labs와 AI 플랫폼 Krea가 협업해 'FLUX.1 Krea [dev]' 모델을 공개했으며 ComfyUI가 즉시 네이티브 지원을 구현했다. Krea의 예술적 스타일 전문성과 FLUX.1 dev 기반 구조를 결합해 스타일 제어력이 크게 향상됐다. HuggingFace에서 무료 다운로드 가능한 오픈 소스 모델이다. FLUX 생태계에서 서드파티 협업 모델이 등장한 첫 사례로 앞으로 다양한 파트너십 모델 출시가 기대된다.
